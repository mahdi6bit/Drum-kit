# Drum-kit

🥁 **Drum Kit – Interactive Drum Machine**

An interactive drum kit web application built with HTML, CSS, and JavaScript. Play different drum sounds using your keyboard or mouse, adjust the master volume, and create your own rhythm!

**Features:**
- Play drum sounds using keyboard keys (W, A, S, D, J, K, L).
- Clickable drum buttons.
- Adjustable volume control.
- Real-time volume level display.
- Responsive and user-friendly interface.

**Technologies Used:**
- HTML5
- CSS3
- JavaScript

🎵 Have fun creating your own beats!
